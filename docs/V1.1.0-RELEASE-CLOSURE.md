# PwdVault v1.1.0 Release Closure

> Date: 2026-07-18
> Platform executed: macOS arm64
> Windows: deferred by scope
> Current decision: local release candidate passes; remote publication requires a version decision

## 1. Outcome

The source tree now passes the local release gates for frontend, Rust workspace,
Native Host, dependency policy, deterministic browser-extension packaging,
Firefox store lint, macOS packaging, and the Phase 5 loopback/adversarial-load
suite.

The already-published `v1.1.0` tag and prerelease point to commit `9ccb641`.
The fixes in this closure are newer than that tag. They must not be presented as
part of the existing remote `v1.1.0` artifacts until one of these actions is
explicitly approved:

1. publish the closure as `v1.1.1` (recommended; preserves immutable release
   history); or
2. move the existing `v1.1.0` tag and replace its prerelease assets (history
   rewrite; requires explicit approval).

No tag, commit, push, release mutation, or remote asset replacement was performed
during this closure run.

## 2. Release-blocking fixes completed

- Added a regression for historical raw-encrypted secrets and empty-password
  records; backup export/import now preserves those records while new-entry
  validation remains strict.
- Aligned all four workspace crates and the Native Host at `1.1.0`, added MIT
  license metadata, pinned internal path dependency versions, and extended
  `bump-version.sh` from 7 to 10 version sources.
- Regenerated both Cargo lockfiles and updated `anyhow` from `1.0.102` to
  `1.0.103`, removing `RUSTSEC-2026-0190`.
- Corrected the active bincode advisory to `RUSTSEC-2025-0141` and made direct
  unmaintained workspace dependencies blocking while documenting upstream
  transitive warnings.
- Fixed Quality/Release workflow gaps: Linux dependencies now run on Ubuntu;
  fmt, ESLint, Native Host, cargo-deny, cargo-audit, npm audit, extension package
  checks, and strict Firefox lint are release gates.
- Hardened `scripts/release.sh`: published tags are immutable and a tag push
  triggers exactly one release workflow instead of a duplicate manual run.
- Removed manual Release workflow dispatch so a build cannot accidentally use
  `main` while replacing assets attached to an older tag.
- Changed CodeQL to retain SARIF as a workflow artifact when GitHub Code Security
  upload is unavailable for this private personal repository.
- Added deterministic, symlink-free Chrome/Firefox ZIP generation and made
  missing/malformed packages fail the release.
- Corrected Firefox MV3 background loading, declared no external data collection,
  raised the minimum supported Firefox version to 142, and eliminated all
  `web-ext` warnings.
- Replaced variable `innerHTML` assignments in the popup and corrected HTML
  escaping to include quotes, closing an attribute-injection boundary.

## 5. Remaining release boundaries

The following are not silently converted to passes:

1. Chrome and Firefox real-browser E2E with the exact candidate ZIPs is pending.
   The installed official Chrome 150 build ignored CLI unpacked-extension
   loading in an isolated profile, so no PwdVault extension context was created;
   Chrome for Testing/Chromium or a manual `chrome://extensions` load is needed.
   Firefox is not installed on the validation machine.
2. CRUD/export/import compatibility is covered by automated service-level
   round-trip tests, including the new historical-record regression. A
   same-process, real-browser, post-load CRUD/export/import journey is still
   pending and requires browser pairing evidence.
3. Windows build/runtime/signature validation is deferred by the agreed scope;
   it must run in GitHub Actions after the closure commit is pushed.
4. macOS Developer ID signing and notarization are unavailable without Apple
   credentials; the candidate is correctly treated as prerelease.
5. The amended Quality, CodeQL, and Release workflows have passed local
   actionlint but require a remote run after push.
6. The current GitHub `v1.1.0` tag predates this closure. Use `v1.1.1` unless
   release history rewrite is deliberately approved.
