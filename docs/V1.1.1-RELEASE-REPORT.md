# PwdVault v1.1.1 Release Report

> Release date: 2026-07-19
> Status: local candidate accepted; remote release execution pending
> Previous immutable release: `v1.1.0` (`9ccb641`)

## Scope

v1.1.1 contains the post-v1.1.0 release-closure fixes documented in
`V1.1.0-RELEASE-CLOSURE.md`. The v1.1.0 tag and assets are intentionally left
unchanged.

## Local acceptance

- Frontend, Rust workspace, and Native Host tests pass.
- TypeScript, ESLint, Rust fmt, and Clippy `-D warnings` pass.
- `cargo-deny`, `cargo-audit`, npm audit, and Gitleaks pass with no known
  vulnerabilities or leaked secrets.
- Gitleaks explicitly classifies the Chrome manifest's public RSA identity key
  as a narrow path/rule/line false positive; no private key material is present.
- Chrome/Firefox packages are deterministic, self-contained, and symlink-free.
- Firefox `web-ext` strict lint reports zero errors, warnings, and notices.
- Phase 5 fast gate and three repeated 1000-client adversarial-load rounds pass.
- macOS app/DMG build and strict ad-hoc signature verification pass locally.

The exact v1.1.1 release binary also passed 16/16 bridge cases before and after
load. Across the three runs, baseline p95 was 2.913–3.200 ms and malformed p95
was 2.149–2.333 ms. Saturation applied the designed bounded-queue backpressure.
After 30 seconds, open files returned 61→61, loopback sockets 1→1, threads
28→29, and RSS changed 105952→106304 KiB.

## Platform boundaries

- macOS Developer ID signing/notarization is not configured; the GitHub release
  must remain a prerelease.
- Firefox is unavailable on the local validation machine. Official Chrome 150
  does not support the previous CLI unpacked-extension automation path; store or
  Chrome-for-Testing browser evidence remains separate from the package gate.
- Windows build/runtime validation executes in GitHub Actions.
